# Aquisição Gama em Campo
Projeto em Python para integrar a obtenção de espectros gama com a obtenção de coordenadas geográficas, para estudos de espectrometria gama em campo.

Este programa foi desenvolvido para o Laboratório de Aplicações Nucleares da Unicentro.

## Links úteis

### Python
Este projeto conta com um arquivo executável, para que não seja necessária a instalação do Python pelo usuário. No entanto, podem ocorrer problemas relacionados com softwares de antivirus no momento de execução. Nesse caso, é possível instalar o Python para poder executar o programa via terminal.

[Download do Python](https://www.python.org/downloads/)

### QGIS
O QGIS será bastante útil para interpretar os dados coletados.

[Download do QGIS](https://www.qgis.org/download/)

### DPPMCA
O DPPMCA é o software da Amptek para leitura e processamento de espectros gama.

[Download do DPPMCA](https://www.amptek.com/software/dp5-digital-pulse-processor-software/dppmca-display-acquisition-software)

### QField
O QField é um aplicativo de celular que pode ser utilizado para registro de coordenadas GPS, gerando um arquivo compatível com o QGIS.

[QField para Android](https://play.google.com/store/apps/details?id=ch.opengis.qfield&hl=pt_BR&pli=1)
[QField para IOS](https://apps.apple.com/br/app/qfield-for-qgis/id1531726814)
